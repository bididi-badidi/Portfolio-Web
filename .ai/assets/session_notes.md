## Gotchas for Next Session
- **Do not revert `color-scheme: dark` in `:root`** — this is required for `light-dark()` and GlassSurface dark fallback to work.
- **`width="auto"` on GlassSurface is intentional** — using a number (e.g. `width={400}`) would fix the pill at a static pixel width; `"auto"` lets it shrink-wrap to the dock items.
- **`glass-surface--dock` class is in `GlassSurface.css`** — if the file is regenerated by shadcn, the modifier will be lost. Keep it documented.
- Bun 1.3.1 does not support `--dom` flag or `environment = "happy-dom"` in bunfig.toml. UI tests require the custom jsdom preload: `bun test --preload ./bun-ui-test-setup.ts`.
